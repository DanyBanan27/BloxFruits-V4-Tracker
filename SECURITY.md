# Security policy

Please do not publish private databases, certificates, signing keys, passwords, or other secrets in issues or pull requests.

For a potential security problem, do not post sensitive details in public issues or in the public Discord. Use GitHub's private vulnerability reporting feature in the repository's Security tab if it is available. For general support, join the [Discord server](https://discord.gg/SvYqcks5Pz).

Release EXEs are not automatically Authenticode-signed. Verify the SHA-256 checksum included with each release before use.
